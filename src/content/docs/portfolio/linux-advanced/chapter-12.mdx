비밀번호를 기억하는 데 의존하는 가족은 비슷한 비밀번호를 여러 곳에 쓰게 됩니다. 비밀번호 관리자는 **사이트마다 다른 긴 비밀번호를 만들고 대신 기억해 주는 금고**입니다. Vaultwarden은 가벼운 직접 운영형 비밀번호 서버이고, 공식 Bitwarden 앱과 확장 프로그램을 그대로 씁니다.

<Note type="danger" title="이 서버에서 가장 중요한 서비스입니다">
금고 서버가 망가지고 백업이 없으면 **가족의 모든 계정에 못 들어갑니다.** Chapter 17의 백업을 끝내고, 복구 시험까지 한 뒤에 가족의 중요한 비밀번호를 옮기세요. 또 **마스터 비밀번호를 잊으면 아무도 복구해 줄 수 없습니다.**
</Note>

<Note type="why" title="이 챕터를 마치면">
- 왜 비밀번호 서버가 HTTPS가 아니면 동작하지 않는지 설명할 수 있다
- Vaultwarden을 설치하고 관리자 화면을 보호할 수 있다
- 가족을 초대하고 공유 보관함을 만들 수 있다
- 마스터 비밀번호 분실에 대비하는 방법을 정할 수 있다
- 금고 데이터를 올바르게 백업할 수 있다
</Note>

## 12.1 왜 HTTPS가 필수인가

비밀번호 보관함의 웹 화면은 브라우저의 **암호 기능(Web Crypto)** 을 씁니다. 브라우저는 이 기능을 HTTPS(또는 같은 컴퓨터의 localhost)에서만 열어 줍니다. 그래서 HTTP로 접속하면 "이 브라우저는 HTTPS가 필요합니다"라는 오류가 나고, 휴대폰 앱과 확장 프로그램도 암호화되지 않은 서버를 거부합니다.

이 과정은 Chapter 3에서 Tailscale 인증서로 HTTPS를 이미 갖췄으므로 Vaultwarden이 바로 동작합니다. 이것이 Chapter 3의 틀을 만든 큰 이유 중 하나입니다.

## 12.2 설치

먼저 관리자 화면용 토큰을 만듭니다. 관리자 화면은 서버 설정을 바꿀 수 있어서 **해시한 값**으로 보호합니다.

<Term title="homeserver (admin)" code={`
$ docker run --rm -it vaultwarden/server /vaultwarden hash
`} />

비밀번호를 두 번 입력하면 `$argon2id$...`로 시작하는 긴 문자열이 나옵니다. 이 문자열을 복사해 둡니다. **입력한 비밀번호는 관리자 화면에 들어갈 때 씁니다.** 설정 파일에는 비밀번호가 아니라 이 해시를 넣습니다.

`/srv/compose/vaultwarden/compose.yaml`

```yaml
services:
  vaultwarden:
    image: vaultwarden/server:latest
    container_name: vaultwarden
    restart: unless-stopped
    environment:
      DOMAIN: "https://homeserver.tail1234.ts.net:8222"
      SIGNUPS_ALLOWED: "true"
      ADMIN_TOKEN: "$$argon2id$$v=19$$m=65540,t=3,p=4$$여기에-나머지-해시"
    volumes:
      - /srv/data/vaultwarden:/data
    ports:
      - "127.0.0.1:18222:80"
```

<Note type="warn" title="해시 안의 달러 기호">
compose 파일에서 `$`는 변수 표시로 읽히기 때문에, 해시의 **모든 `$`를 `$$`로** 바꿔 써야 합니다(위 예시처럼). 바꾸지 않으면 관리자 화면에 로그인되지 않습니다.
</Note>

<Term title="homeserver (admin)" code={`
$ mkdir -p /srv/compose/vaultwarden /srv/data/vaultwarden
$ cd /srv/compose/vaultwarden
$ chmod 600 compose.yaml
$ docker compose up -d
`} />

Caddyfile에 8222 칸(안쪽 18222)을 추가하고 다시 읽은 뒤 `https://homeserver.tail1234.ts.net:8222`를 엽니다.

## 12.3 첫 계정과 가입 닫기

1. 처음 열면 **계정 만들기**를 누르고 본인 이메일과 마스터 비밀번호로 가입합니다.
2. 가입을 마치면 compose의 `SIGNUPS_ALLOWED`를 `"false"`로 바꾸고 다시 시작합니다. 이후에는 아무나 계정을 만들 수 없습니다.

<Term title="homeserver (admin)" code={`
$ sed -i 's/SIGNUPS_ALLOWED: "true"/SIGNUPS_ALLOWED: "false"/' compose.yaml
$ docker compose up -d
`} />

3. 가족을 초대하려면 관리자 화면(`/admin`, 위에서 정한 비밀번호)의 사용자 항목에서 **가족의 이메일로 초대**합니다. 메일 서버(SMTP)를 연결하지 않았다면 초대 메일은 가지 않지만, 가족이 **같은 이메일로 직접 계정 만들기**를 하면 가입이 허용됩니다.

### 마스터 비밀번호

마스터 비밀번호는 금고의 열쇠이고, 서버에도 저장되지 않습니다. 좋은 마스터 비밀번호는 **긴 문장**입니다. 예를 들어 서로 관련 없는 단어 4~5개를 이어 붙인 것이 짧고 복잡한 글자 조합보다 안전하고 외우기 쉽습니다.

| 분실 대비 방법 | 설명 |
|---|---|
| 종이에 적어 안전한 곳에 | 금고나 서랍. 가족에게 위치를 알려 둔다 |
| 비상 접근(Emergency Access) | 지정한 가족이 일정 대기 시간 후 금고에 접근할 수 있는 기능. 지원 여부와 설정은 공식 문서 확인 |
| 관리자에게 맡기기(권장하지 않음) | 한 사람이 모두의 열쇠를 갖는 것은 위험하다 |

## 12.4 앱 연결과 가족 공유

각 가족이 아래 순서로 연결합니다.

1. **Bitwarden** 앱(휴대폰)과 브라우저 확장 프로그램을 설치합니다. 앱 이름은 공식 Bitwarden입니다.
2. 로그인 화면에서 **서버 주소를 자체 호스팅(self-hosted)으로 바꿉니다.** 로그인 **전에** 설정해야 합니다. 주소는 `https://homeserver.tail1234.ts.net:8222`입니다.
3. 이메일과 마스터 비밀번호로 로그인합니다.
4. 기존 비밀번호는 브라우저(크롬, 사파리)에서 **CSV로 내보낸 뒤 가져오기**를 하고, **CSV 파일은 바로 영구 삭제**합니다. 이 파일에는 모든 비밀번호가 평문으로 들어 있습니다.

### 가족 공유 보관함

개인 보관함과 별도로 **조직(Organization)** 을 만들어 가족이 함께 쓸 비밀번호(와이파이, 공용 서비스 계정, 통신사 계정)를 담습니다.

<Mini title="공유할 것과 말 것">
가족 공유 보관함에 넣으면 좋은 것과 넣으면 안 되는 것을 나눠 보세요.

<Answer>
**넣을 것**: 집 와이파이, 가족이 함께 쓰는 서비스 계정(영상, 음악), 공과금과 통신사 계정, 응급 시 필요한 정보(보험, 병원). **넣지 말 것**: 개인 이메일, 은행 계정, 개인 SNS처럼 한 사람의 사생활이거나 금전 피해가 큰 계정. 공유는 컬렉션 단위로 권한을 나눌 수 있으니 필요한 사람에게만 열어 주세요.
</Answer>
</Mini>

<Note type="tip" title="2단계 인증을 켜세요">
금고 계정에도 2단계 인증(인증 앱)을 켜는 것이 안전합니다. 단, **인증 앱과 복구 코드를 잃으면 금고에도 못 들어갑니다.** 복구 코드를 종이로 인쇄해 마스터 비밀번호와 따로 보관하세요.
</Note>

## 12.5 백업

Vaultwarden의 데이터는 `/srv/data/vaultwarden`에 있고, 핵심은 데이터베이스 파일입니다. 파일을 그냥 복사하면 사용 중인 파일이 중간 상태로 복사될 수 있어서, **전용 백업 명령**을 씁니다.

<Term title="homeserver (admin)" code={`
$ docker exec vaultwarden /vaultwarden backup
$ ls -l /srv/data/vaultwarden
`} />

데이터 폴더에 백업 파일(`db_날짜.sqlite3`)이 생깁니다. Chapter 17에서 이 폴더 전체와 이 명령의 실행을 자동 백업에 포함합니다. 명령 이름과 위치는 버전에 따라 다를 수 있으니 Vaultwarden 위키의 Backing up 항목을 확인하세요.

<Lab id="12-1" title="금고 열기" time="1시간 30분">

- [ ] HTTPS 주소에서 Vaultwarden 화면이 열린다
- [ ] 관리자 해시를 만들었고 `/admin`에 로그인된다
- [ ] 내 계정을 만든 뒤 `SIGNUPS_ALLOWED`를 `false`로 바꿨다
- [ ] 휴대폰 앱의 서버 주소를 자체 호스팅으로 바꾸고 로그인했다
- [ ] 비밀번호 5개를 가져오기로 옮기고 CSV 파일을 삭제했다
- [ ] 가족 1명을 초대해 가입시켰다
- [ ] 마스터 비밀번호와 복구 코드를 종이에 적어 안전한 곳에 뒀다
- [ ] `vaultwarden backup` 명령으로 백업 파일이 생기는 것을 확인했다
- [ ] 서버 노트의 종이 비밀번호를 금고로 옮기고 종이를 안전하게 폐기했다

</Lab>

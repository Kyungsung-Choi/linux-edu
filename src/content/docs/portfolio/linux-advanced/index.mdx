집에 서버 한 대를 두고 **나와 가족만 쓰는 서비스**를 올리는 과정입니다. 서버 안에서 일하는 클로드(Claude Code)와, 사진·비밀번호·광고 차단 같은 가족 서비스를 한 대에 담습니다.

선수 과정은 [리눅스 입문](/portfolio/linux/) 12챕터입니다.

## 이 과정의 원칙

1. **밖에서 들어오는 문을 만들지 않는다.** 공유기 포트포워딩 대신 Tailscale로 접속합니다. 공인 고정 IP가 없어도 됩니다.
2. **클로드는 관리자만 쓴다.** 가족 계정에는 서버 명령 권한을 주지 않습니다.
3. **백업 없이 소중한 자료를 올리지 않는다.**

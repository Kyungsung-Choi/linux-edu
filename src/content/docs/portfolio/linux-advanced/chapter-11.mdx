가족 행사 영상, 직접 녹화한 영상, 구입해 가진 음악이 여기저기 흩어져 있다면 **한 곳에서 보여 주는 서비스**가 필요합니다. Jellyfin이 그 일을 합니다. 이 챕터의 핵심 과제는 **거실 TV에서 어떻게 보느냐**입니다.

<Note type="why" title="이 챕터를 마치면">
- Jellyfin을 설치하고 영상·음악 폴더를 연결할 수 있다
- 가족 계정과 아이용 제한을 설정할 수 있다
- tailnet 규칙과 거실 TV 사이의 충돌을 이해하고 해결할 수 있다
- 집 밖 시청의 한계(업로드 속도)를 설명할 수 있다
</Note>

<Note type="tip" title="올리는 자료에 대해">
이 서비스에 올리는 것은 **직접 촬영했거나, 합법적으로 가진 자료**로 하세요. 가정의 서버라도 저작권 있는 영상을 가족 밖으로 퍼뜨리지 않는 구조(공개하지 않는 것)를 이 과정이 택한 이유이기도 합니다.
</Note>

## 11.1 설치

`/srv/compose/jellyfin/compose.yaml`

```yaml
services:
  jellyfin:
    image: jellyfin/jellyfin
    container_name: jellyfin
    restart: unless-stopped
    user: "1000:1000"
    ports:
      - "192.168.0.50:8096:8096"
    volumes:
      - /srv/data/jellyfin/config:/config
      - /srv/data/jellyfin/cache:/cache
      - /srv/media/video:/media/video:ro
      - /srv/media/music:/media/music:ro
    devices:
      - /dev/dri:/dev/dri
```

- `192.168.0.50`은 Chapter 1에서 예약한 **서버의 집 안 주소**입니다. 본인 값으로 바꾸세요.
- `user: "1000:1000"`은 관리자 계정의 번호입니다. `id` 명령으로 확인합니다.
- 미디어 폴더는 `:ro`(읽기 전용)로 연결해 서비스가 원본을 건드리지 못하게 합니다.
- `/dev/dri`는 CPU에 내장된 영상 처리 장치입니다. 이 장치가 없는 기기는 `devices` 줄을 지웁니다. 하드웨어 변환 설정은 Jellyfin 공식 문서에서 기기에 맞게 확인하세요.

<Term title="homeserver (admin)" code={`
$ id
$ mkdir -p /srv/compose/jellyfin /srv/data/jellyfin/config /srv/data/jellyfin/cache /srv/media/video /srv/media/music
$ cd /srv/compose/jellyfin && docker compose up -d

## 11.2 거실 TV 문제와 해결

### 충돌

Chapter 3에서 모든 서비스를 tailnet 안에서만 열었습니다. 그런데 **거실 TV, 셋톱박스, 구형 태블릿**은 Tailscale 앱을 설치할 수 없는 경우가 많습니다. 그러면 `https://homeserver.tail1234.ts.net:8096` 주소로 접속할 수 없습니다.

### 선택지

| 방법 | 설명 | 판단 |
|---|---|---|
| **집 안 주소로 직접 열기(HTTP)** | 서버의 집 안 주소(`192.168.0.50:8096`)로 TV가 접속 | **영상만 이 방식. 위 compose처럼 집 안 주소에만 열었다** |
| TV에 Tailscale 설치 | 안드로이드 TV·애플 TV 등은 앱이 있다 | TV가 지원하면 가장 일관된 방법 |
| 별도 재생 기기 | 작은 안드로이드 TV 박스를 TV에 연결하고 Tailscale 설치 | 비용이 든다 |

위 compose는 Jellyfin을 **집 안 공유기 쪽 주소에만** 열었습니다. 인터넷에서는 접근할 수 없고(공유기가 막고 있음), 같은 집 와이파이에 있는 기기만 접속합니다. 즉, 영상 서비스는 다른 서비스보다 **한 단계 낮은 보안 수준**(집 안 모든 기기를 신뢰)을 의도적으로 택한 것입니다.

<Note type="warn" title="손님의 와이파이">
집 안 주소로 열린 서비스는 **같은 와이파이에 접속한 사람이면 누구나 접속 화면을 볼 수 있습니다.** 로그인은 필요하지만, 손님이 오면 공유기의 손님 와이파이(Guest) 기능으로 가족용 네트워크와 분리하세요. 서비스 계정 비밀번호를 쉬운 것으로 하지 마세요.
</Note>

### 집 밖에서 볼 때

집 밖의 가족은 Tailscale을 켜고 Caddy의 HTTPS 주소로 접속합니다. Caddyfile에 칸을 추가합니다.

```
https://{$TS_HOST}:8096 {
	bind {$TS_IP}
	tls /certs/ts.crt /certs/ts.key
	reverse_proxy 192.168.0.50:8096
}
```

Jellyfin은 `192.168.0.50:8096`에, Caddy는 `100.x.y.z:8096`에 각각 문을 여는 구조라 포트 번호는 같아도 충돌하지 않습니다(주소가 다릅니다). Chapter 3의 포트표에서 Jellyfin의 서버 안 포트 칸은 이 챕터의 방식으로 바뀐다고 적어 두세요.

## 11.3 설정과 폴더 정리

처음 접속(`http://192.168.0.50:8096`)하면 설정 마법사가 나옵니다.

1. 관리자 계정을 만듭니다.
2. **라이브러리 추가**: 종류(영화, 홈 비디오, 음악)와 폴더(`/media/video`, `/media/music`)를 고릅니다.
3. 메타데이터 언어를 한국어로 지정합니다.
4. 마법사의 **원격 접속 허용**은 켜 두되, 공유기에 포트를 열지는 않습니다.

폴더 이름을 규칙대로 두면 정보가 자동으로 붙습니다. 가족 영상은 `홈 비디오` 라이브러리로 만들면 영화 정보를 찾으려 하지 않아 정리가 쉽습니다.

```
/srv/media/video/
  가족영상/2026-여름휴가/해변.mp4
  영화/영화이름 (2019)/영화이름 (2019).mkv
```

## 11.4 가족 계정과 아이용 제한

관리 메뉴의 사용자에서 가족마다 계정을 만듭니다.

| 설정 | 용도 |
|---|---|
| 라이브러리 접근 | 아이 계정에는 일부 라이브러리만 보이게 한다 |
| 관람 등급 제한 | 아이 계정에서 특정 등급 이상 영상을 숨긴다 |
| 관리자 권한 | 가족에게 주지 않는다 |

<Mini title="가족 계정의 권한">
가족 계정에 "관리자 권한"을 주지 말라고 한 이유는 무엇일까요?

<Answer>
관리자는 라이브러리 폴더 설정, 사용자 추가·삭제, 플러그인 설치를 할 수 있습니다. 서비스가 서버에서 실행되는 만큼 **설정이나 플러그인을 통해 서버의 다른 자료에 영향을 줄 수 있는 경로**가 생깁니다. 일상적인 시청에는 필요 없는 권한입니다. 계정마다 필요한 권한만 주는 것은 입문 Chapter 4의 원칙과 같습니다.
</Answer>
</Mini>

## 11.5 집 밖 시청의 한계

집 밖에서 영상을 보면 **서버가 내 집 인터넷의 업로드 속도로 영상을 보냅니다.** 가정용 인터넷은 다운로드는 빠르지만 업로드는 느린 경우가 많습니다.

| 영상 | 대략 필요한 속도 |
|---|---|
| 휴대폰용 낮은 화질 | 2~4Mbps |
| 1080p 일반 영상 | 8~20Mbps 안팎 |
| 4K 고화질 원본 | 40Mbps 이상 |

(어림값입니다. 영상마다 다릅니다.) 집 인터넷의 **업로드 속도**를 속도 측정 사이트로 재서 비교하세요. 부족하면 집 밖 시청은 Jellyfin의 화질 제한 설정(재생 설정의 인터넷 스트리밍 비트레이트 한도)으로 낮춰서 보내게 합니다. 서버가 화질을 낮춰 다시 인코딩하는 **변환**은 CPU를 많이 쓰므로, 하드웨어 변환이 되는 기기인지 확인하세요.

또 Tailscale은 두 기기가 직접 연결을 못 하면 **중계 서버를 거치는데, 이때 속도가 낮아질 수 있습니다.** `tailscale status`에서 상대가 `direct`로 보이는지 확인하세요.

<Lab id="11-1" title="우리 집 극장 열기" time="1시간 30분">

- [ ] Jellyfin이 실행 중이고 `192.168.0.50:8096`(본인 주소)으로 집 안에서 열린다
- [ ] 영상과 음악 라이브러리를 만들고 영상 1개를 재생했다
- [ ] 거실 TV나 셋톱박스에서 접속하는 방법을 찾아 시험했다
- [ ] 가족 계정을 만들고, 아이 계정에 관람 등급을 설정했다
- [ ] 휴대폰으로 집 밖에서 HTTPS 주소로 접속해 낮은 화질로 재생했다
- [ ] 집 인터넷의 업로드 속도를 재서 서버 노트에 적었다
- [ ] 손님 와이파이가 분리되는지 공유기에서 확인했다

</Lab>

"React UI 문서의 컴포넌트와 웹사이트 시안을 둘러보면 외워진다"는 말은, 잘 만든 화면 부품과 사이트를 자주 볼수록 "이런 화면엔 이런 부품을 쓰는구나"가 자연스럽게 머릿속에 남는다는 뜻입니다.

## 왜 AI에게 유용한가

- 이름을 알면 "그 파란 상자 같은 거" 대신 "Alert 컴포넌트"라고 정확히 요청할 수 있습니다.
- "카드형 레이아웃에 사이드바, 상세는 모달로"처럼 구조를 말로 정해 주면 결과물이 훨씬 좋아집니다.
- 마음에 드는 시안을 보고 어떤 부품으로 만들었는지 알아 두면 같은 느낌을 다시 만들기 쉽습니다.

## 이렇게 해 보세요

1. shadcn/ui 같은 문서에서 컴포넌트 목록을 한 번 쭉 훑어봅니다.
2. One Page Love나 Awwwards에서 마음에 드는 사이트 3~5개를 저장합니다.
3. "이건 어떤 컴포넌트로 만들었을까?" 하고 이름을 붙여 봅니다 (Card, Tabs, Dialog 등).
4. AI에게 시킬 때 그 이름으로 요청합니다.

## React UI 컴포넌트 문서

버튼, 카드, 모달, 탭 같은 화면 부품(컴포넌트)이 이름과 함께 정리된 문서입니다. 이름을 알아야 AI에게 정확히 시킬 수 있습니다.

- [shadcn/ui](https://ui.shadcn.com/): 요즘 가장 많이 쓰는 컴포넌트 모음. 복사해서 바로 쓸 수 있고 AI에게 이름을 대기 좋습니다.
- [MUI](https://mui.com/): 구글 Material 디자인 기반. 컴포넌트 종류가 아주 많습니다.
- [Ant Design](https://ant.design/): 관리자 화면, 표, 폼에 강합니다.
- [Chakra UI](https://chakra-ui.com/): 가볍고 배우기 쉬운 컴포넌트 라이브러리.
- [Radix UI](https://www.radix-ui.com/): 접근성이 좋은 기본 부품. shadcn/ui의 바탕입니다.
- [Mantine](https://mantine.dev/): 컴포넌트와 훅이 풍부한 라이브러리.

## 컴포넌트를 모아 보는 곳

완성된 부품을 구경하고 가져다 쓸 수 있는 모음 사이트입니다.

- [21st.dev](https://21st.dev/): shadcn 기반 컴포넌트를 모아 둔 커뮤니티.
- [Magic UI](https://magicui.design/): 애니메이션이 들어간 랜딩 페이지용 부품.
- [Aceternity UI](https://ui.aceternity.com/): 눈에 띄는 효과가 있는 부품 모음.
- [Flowbite](https://flowbite.com/): Tailwind CSS 기반 부품 모음.
- [daisyUI](https://daisyui.com/): Tailwind CSS 위에 얹는 컴포넌트 모음.
- [Tailwind Plus (Tailwind UI)](https://tailwindcss.com/plus): Tailwind 제작사의 공식 부품·템플릿(유료).

## 웹사이트 시안·디자인 영감

잘 만든 사이트와 시안을 많이 볼수록 "이런 화면에는 이런 부품을 쓰는구나"가 감각으로 남습니다.

- [Awwwards](https://www.awwwards.com/): 수상작 사이트 모음.
- [One Page Love](https://onepagelove.com/): 원페이지 사이트 모음. 포트폴리오 참고용.
- [Dribbble](https://dribbble.com/): 디자이너들의 시안 모음.
- [Behance](https://www.behance.net/): 디자인 작업물 포트폴리오 모음.
- [Mobbin](https://mobbin.com/): 실제 앱 화면 모음(일부 유료).
- [Land-book](https://land-book.com/): 랜딩 페이지 모음.
- [Godly](https://godly.website/): 감각적인 웹사이트 모음.
- [Refero](https://refero.design/): 실제 서비스 화면 레퍼런스.
